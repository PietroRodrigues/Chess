# Chess

A chess game project developed with **Unity**, created as a practical exploration of game development, 3D assets, and interactive systems.

## About

This repository contains the Unity project and its associated assets for a chess game. The project includes the Unity `Assets`, `Packages`, and `ProjectSettings` structure, as well as a dedicated `BlenderModel` directory for 3D modeling resources.

## Technologies

- **Unity 2020.3.17f1**
- **C#**
- **Blender** — 3D asset creation

## Project Structure

```text
Chess/
├── Assets/          # Unity assets and game resources
├── BlenderModel/    # 3D modeling resources
├── Packages/        # Unity package configuration
├── ProjectSettings/ # Unity project configuration
└── README.md
```

## Purpose

The project was created to practice game development concepts using Unity and C#, while also exploring the creation and integration of 3D assets.

## Status

This is a personal game-development project and may not represent a complete production-ready chess game. The repository is kept as part of the development history and portfolio.
